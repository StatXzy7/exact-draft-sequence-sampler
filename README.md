# exact-draft-sequence-sampler

运行于 Linux CPU（纯 Rust，无模型下载、无外部服务、**零第三方运行时依赖**）的
有限词表序列采样器。轻量“草稿”分布每轮提出连续候选，目标条件分布逐位核验，
最终提交序列的分布与**逐词直接按目标分布采样完全一致**。

## 算法

每轮（`Sampler::step`）交错执行提议与核验，保证每次查询都基于**真实前缀**：

1. 在“已提交前缀 + 本轮已连续接受的草稿前缀”上查询草稿分布 `q`，提出一个词；
2. 在同一真实前缀上查询目标分布 `p`，以概率 `min(1, p(x)/q(x))` 接受该词；
3. 首次拒绝：只提交之前的连续接受前缀，该位置及其后草稿全部丢弃，并用
   归一化纠偏（残差）分布
   `r(x) = (p(x) - q(x))_+ / Σ_y (p(y) - q(y))_+`
   恰好补出一个词；
4. 整窗全部接受时，允许再按目标分布额外采一个词（bonus）；
5. 结束符一旦提交立即停止；提交长度绝不超过 `max_len`。

**输出分布一致性**：接受贡献为 `q(x)·min(1,p/q)=min(p,q)`，纠偏贡献合计为
`(p-q)_+`，两者相加恰为 `p(x)`，与草稿无关。
**单位置接受率**：`Σ_x min(p(x), q(x))`，即两分布的重叠质量。
目标与草稿完全相同 ⇒ 重叠质量 1、残差为零，绝不进入纠偏分支（实现里零残差
仍发生拒绝会显式报错 `ZeroResidualMass`，而不是除以零）；支持不相交 ⇒ 残差
就是目标分布本身。

随机源为可完整快照的 xoshiro256\*\*（SplitMix64 由种子派生 256-bit 状态），
检查点保存 4 个 `u64` 内部状态字，因此**仅重置初始种子无法冒充恢复**。

## 配置与查询

- `Config { window, max_len, eos }`：草稿窗口、输出长度上限、结束符；
- `ConditionalTable` trait：本地条件概率表，`MapTable` 为内置实现；
  构造时逐行校验：负概率、NaN/±∞、总质量偏离 1（容差可配）、重复词、
  全零行都会构造失败；
- 查询仅使用真实前缀；缺少前缀分布返回 `MissingPrefix`；
- 任何一轮失败都在提交前返回，**已提交序列与轮计数不变**，也不写检查点。

## 检查点

`save_checkpoint(path)` 在每轮提交后调用；文件为可读文本，含配置、目标/草稿
表指纹、轮次、序列与 RNG 全状态。`Sampler::restore_from_file(target, draft,
config, path)` 校验版本、配置与表指纹，不匹配时显式失败（`CheckpointMismatch` /
`CorruptCheckpoint`），恢复后后续每一轮的提议、接受/拒绝、纠偏、bonus 事件都与
同种子不中断运行一致。

## 运行示例

```bash
cargo run --release -- --window 3 --max-len 20 --seed 12345 \
    --checkpoint checkpoint.txt
cargo run --release -- --resume --window 3 --max-len 20 \
    --checkpoint checkpoint.txt
```

## 测试

```bash
cargo test
```

共 22 个测试（含库内单测与 4 个集成测试文件），均为行为断言，不只是启动检查：

- `tests/exact_law.rs`：多组（目标, 草稿）对（相同、不相交、部分重叠、包含
  关系）的整数/有理数枚举，逐词验证输出质量严格等于目标质量、总量为 1，
  接受率等于重叠质量，相同⇒1、不相交⇒0；
- `tests/empirical.rs`：固定种子的大样本经验检验——投机采样的序列分布与
  “草稿=目标”的直接采样一致（最大格点偏差阈值）、单位置经验接受率 ≈ 0.7
  的理论重叠、相同分布 5 万轮零纠偏、不相交支持时纠偏词分布等于目标分布、
  零概率词从不出现；
- `tests/events.rs`：脚本化随机流断言首拒截止与丢弃尾部、查询只打到真实
  前缀（含查询日志断言）、接受 EOS 立即停轮且无 bonus、长度上限抑制多余提议
  与 bonus、最后一个槽位纠偏恰好填满、全接受时 bonus 一个目标词；
- `tests/resume_and_errors.rs`：恢复点逐事件复现不中断运行、仅重置种子
  不能复现恢复后事件、配置/表指纹/损坏检查点显式失败、非法分布轮失败不改已
  提交结果、缺少前缀干净失败、表构造期的负概率/非有限数/总质量/空支持校验。
